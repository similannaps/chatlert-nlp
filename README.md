## 📝 บทนำและที่มาของปัญหา (Problem Statement)
ในปัจจุบันร้านค้าออนไลน์มีการสื่อสารกับลูกค้าผ่านระบบแชทเป็นจำนวนมาก (เช่น การสอบถามสินค้า สถานะการจัดส่ง หรือแจ้งชำระเงิน) แต่อุปสรรคสำคัญคือ **ลูกค้ามักใช้ "ภาษาแชท" ที่ไม่เป็นทางการ** เช่น การใช้คำแสลง คำย่อ หรือการพิมพ์ตัวอักษรซ้ำ (เช่น *"ของส่งยังงงง"*, *"สนจัยตัวนี้อยุ่ มีสีไรบ้าง"*) 

ข้อความที่กำกวมเหล่านี้ทำให้ระบบแชทบอทอัตโนมัติ (Auto-reply) ไม่สามารถประมวลผลคำวิบัติได้ ทำให้เกิดความผิดพลาดในการตอบกลับ และแอดมินต้องเสียเวลาในการตีความ **ระบบ ChatLert** จึงถูกพัฒนาขึ้นโดยใช้เทคนิค **NLP (Natural Language Processing)** เพื่อปรับข้อความจากภาษาแชทให้เป็นภาษาไทยมาตรฐาน และวิเคราะห์เจตนา (Intent) ของลูกค้าได้อย่างถูกต้องแม่นยำ

## 📥 ข้อมูลนำเข้าและผลลัพธ์ (Input & Output)

| ข้อมูลนำเข้า (Input) | ภาษามาตรฐาน (Normalized Text) | เจตนา (Intent) |
| :--- | :--- | :--- |
| `ของส่งยังงงง` | สินค้าจัดส่งแล้วหรือยังครับ | สอบถามสถานะสินค้า |
| `สนจัยตัวนี้อยุ่` | สนใจตัวนี้อยู่ครับ | สอบถามรายละเอียดสินค้า |
| `โอนแล้วน้าา เช็คให้ทีงับ` | โอนแล้ว เช็คให้ทีครับ | แจ้งชำระเงิน |

## 🚀 กระบวนการทำงาน (NLP Pipeline 8 ขั้นตอน)

ระบบประมวลผลผ่าน Pipeline 8 ขั้นตอน เพื่อแปลงข้อความให้สมบูรณ์ที่สุด:

1. **การทำความสะอาดข้อความ (Text Cleaning):** 
   ลบสัญลักษณ์พิเศษหรืออีโมจิที่ไม่จำเป็นออกโดยใช้ Regular Expression
   * *Input:* `โอนแล้วน้าา 😊` ➡️ *Output:* `โอนแล้วน้าา`
2. **การลดตัวอักษรซ้ำ (Reduce Repeated Characters):** 
   ลดจำนวนตัวอักษรที่พิมพ์ซ้ำซ้อนเพื่อแสดงอารมณ์ให้เหลือรูปแบบปกติ
   * *Input:* `รอนานมากกกก` ➡️ *Output:* `รอนานมาก`
3. **การปรับคำแสลงเป็นคำมาตรฐาน (Slang Normalization):** 
   ตรวจสอบคำวิบัติและแทนที่ด้วยคำมาตรฐานผ่าน SLANG Dictionary
   * *ตัวอย่าง:* `งับ/ค้าบ` ➡️ `ครับ`, `สนจัย` ➡️ `สนใจ`, `อยุ่` ➡️ `อยู่`, `มั้ย` ➡️ `ไหม`, `เด่ว` ➡️ `เดี๋ยว`
4. **การตัดคำภาษาไทย (Word Tokenization):** 
   แบ่งประโยคเป็นคำๆ เนื่องจากภาษาไทยไม่มีการเว้นวรรค (ใช้ `PyThaiNLP`)
   * *Input:* `สนใจตัวนี้อยู่มีสีอะไรบ้าง` ➡️ *Output:* `["สนใจ", "ตัว", "นี้", "อยู่", "มี", "สี", "อะไร", "บ้าง"]`
5. **การลบคำขยะที่ไม่จำเป็น (Token Cleaning):** 
   นำคำหรือ Token ที่ไม่มีความหมายออก (เช่น คำว่า "อะะะ", "น้าา")
   * *Input:* `โอนแล้วน้าา` ➡️ *Output:* `โอนแล้ว`
6. **การปรับโครงสร้างประโยค (Sentence Adjustment):** 
   ปรับรูปแบบคำให้เป็นประโยคที่เข้าใจง่ายขึ้นตามกฎ
   * *ตัวอย่าง:* หากพบคำว่า `"ส่ง"` + `"ยัง"` ➡️ `สอบถามสถานะการจัดส่ง`
7. **การเติมคำสุภาพ (Add Polite Particle):** 
   เติมหางเสียง (ครับ/ค่ะ) เพื่อให้ประโยคมีความสุภาพมากขึ้น
   * *Input:* `สินค้าจัดส่งแล้วหรือยัง` ➡️ *Output:* `สินค้าจัดส่งแล้วหรือยังครับ/ค่ะ`
8. **การจำแนกเจตนา (Intent Classification):** 
   วิเคราะห์ความต้องการของลูกค้าจากคีย์เวิร์ด
   * *ตัวอย่าง:* `ส่งของยัง` ➡️ `สอบถามสถานะสินค้า`

## 🧠 ความสามารถขั้นสูง (Advanced Capabilities)

### 1. การจัดการความกำกวมของภาษา (Ambiguity Management)
* **ระดับคำ (Lexical Ambiguity):** คำว่า *"ขอเปลี่ยนหน่อย"* อาจหมายถึงเปลี่ยนสินค้า, เปลี่ยนไซส์, หรือเปลี่ยนที่อยู่ ระบบจะดูบริบทรอบข้าง เช่น *"เสื้อตัวนี้ไซส์เล็กไป ขอเปลี่ยนหน่อย"* ระบบจะตีความว่าเป็นการ **"ขอเปลี่ยนไซส์สินค้า"**
* **โครงสร้างประโยค (Structural Ambiguity):** คำว่า *"ถึงไหนแล้ว"* ระบบจะตีความหมายว่า *"สินค้าถึงขั้นตอนไหนของการจัดส่งแล้ว"*
* **ภาษาพูด (Informal Language):** *"ได้ของยัง"* จะถูกตีความหมายจริงคือ *"ได้รับสินค้าแล้วหรือยัง"*

### 2. การสกัดข้อมูล (Information Extraction)
ระบบสามารถดึงคีย์เวิร์ดสำคัญ เช่น ประเภทสินค้า สี ไซส์ และราคา
* *Input:* `เสื้อตัวนี้มีสีอะไร` ➡️ *Output:* `Product: เสื้อ`, `Attribute: Color`

### 3. การจัดกลุ่มและจำแนก (Classification & Clustering)
จัดกลุ่มข้อความตามความหมาย เช่น กลุ่มสอบถามสถานะ (`ของส่งยัง`, `พัสดุถึงไหนแล้ว`) และกลุ่มแจ้งชำระเงิน (`โอนแล้ว`, `โอนเงินเรียบร้อย`)

## 🔗 การทำงานร่วมกับ MatchaQ (System Integration)

ระบบ ChatLert ถูกนำมาใช้งานเชื่อมโยงกับระบบ **MatchaQ** (ระบบวิเคราะห์ Job Description และ Portfolio) โดยแบ่งหน้าที่กันดังนี้:
* **ChatLert (Data Preprocessing):** ตรวจสอบ แก้ไขคำสะกดผิด และปรับภาษาแชทให้เป็นมาตรฐาน เพื่อลดปัญหาการตีความผิดพลาด
* **MatchaQ (Core Analytics):** รับข้อความที่ถูกต้องจาก ChatLert ไปสกัดคีย์เวิร์ด/ทักษะ เพื่อประเมินคะแนนความสอดคล้อง (Matching Score) ต่อไป

## 💻 การติดตั้งและการใช้งาน (Installation & Usage)

1. **โคลนโปรเจกต์ (Clone the repository)**
   ```bash
   git clone https://github.com/simi200511-alt/ChatLert.git
   cd ChatLert
   ```

2. **สร้าง Virtual Environment (แนะนำ)**
   ```bash
   python -m venv venv
   # สำหรับ Mac/Linux
   source venv/bin/activate  
   # สำหรับ Windows
   venv\Scripts\activate
   ```

3. **ติดตั้งไลบรารี (Install dependencies)**
   ```bash
   pip install -r requirements.txt
   ```

4. **รันแอปพลิเคชัน (Run the app)**
   ```bash
   streamlit run app.py
   ```
   *ระบบจะเปิดหน้าต่างเบราว์เซอร์อัตโนมัติที่ `http://localhost:8501`*
