## 📝 บทนำและที่มาของปัญหา (Problem Statement)
ในปัจจุบันร้านค้าออนไลน์มีการสื่อสารกับลูกค้าผ่านระบบแชทเป็นจำนวนมาก (เช่น การสอบถามสินค้า สถานะการจัดส่ง หรือแจ้งชำระเงิน) แต่อุปสรรคสำคัญคือ **ลูกค้ามักใช้ "ภาษาแชท" ที่ไม่เป็นทางการ** เช่น การใช้คำแสลง คำย่อ หรือการพิมพ์ตัวอักษรซ้ำ (เช่น *"ของส่งยังงงง"*, *"สนจัยตัวนี้อยุ่ มีสีไรบ้าง"*)

ข้อความที่กำกวมเหล่านี้ทำให้ระบบแชทบอทอัตโนมัติ (Auto-reply) ไม่สามารถประมวลผลคำวิบัติได้ ทำให้เกิดความผิดพลาดในการตอบกลับ และแอดมินต้องเสียเวลาในการตีความ **ระบบ ChatLert** จึงถูกพัฒนาขึ้นโดยใช้เทคนิค **NLP (Natural Language Processing)** เพื่อปรับข้อความจากภาษาแชทให้เป็นภาษาไทยมาตรฐาน และวิเคราะห์เจตนา (Intent) ของลูกค้า

## 📥 ข้อมูลนำเข้าและผลลัพธ์ (Input & Output)
ผลด้านล่างได้จากการรันเอนจิน v2.0 จริง

| ข้อมูลนำเข้า (Input) | ภาษามาตรฐาน (Normalized Text) | เจตนา (Intent) |
| :--- | :--- | :--- |
| `ของส่งยังงงง` | สินค้าจัดส่งแล้วหรือยัง | สอบถามสถานะสินค้า |
| `สนจัยตัวนี้อยุ่` | สนใจตัวนี้อยู่ | สอบถามรายละเอียดสินค้า |
| `โอนแล้วน้าา เช็คให้ทีงับ` | โอนเงินเรียบร้อยแล้ว ตรวจสอบให้ด้วยครับ | แจ้งชำระเงิน |
| `ทำไมส่งช้าจังงงงงง` | จัดส่งสินค้าล่าช้า ต้องการให้ตรวจสอบ | ร้องเรียนการจัดส่ง |

ระบบจะเติมหางเสียงก็ต่อเมื่อลูกค้าพิมพ์หางเสียงมาเอง (เช่น `คะ` `ค่ะ` `ครับ` `งับ`)

## 🚀 กระบวนการทำงาน (NLP Pipeline 8 ขั้นตอน)

1. **การทำความสะอาดข้อความ (Text Cleaning):** ลบสัญลักษณ์พิเศษและอีโมจิด้วย Regular Expression
   * `โอนแล้วน้าา 😊` ➡️ `โอนแล้วน้าา`
2. **การลดตัวอักษรซ้ำ (Reduce Repeated Characters):** ตัวซ้ำ 3 ตัวขึ้นไปลดเหลือ 1 ตัว ส่วนตัวซ้ำคู่ลดเฉพาะสระ า ะ ี หรือที่ท้ายคำ และไม่แตะคำที่ซ้ำตามปกติ เช่น "ออเดอร์" "จัดสรร"
   * `รอนานมากกกก` ➡️ `รอนานมาก`
3. **การปรับคำแสลงเป็นคำมาตรฐาน (Slang Normalization):** แทนคำด้วยกฎ Regular Expression ที่ตรวจขอบเขตคำ
   * `งับ/ค้าบ` ➡️ `ครับ`, `สนจัย` ➡️ `สนใจ`, `อยุ่` ➡️ `อยู่`, `มั้ย` ➡️ `ไหม`, `เด่ว` ➡️ `เดี๋ยว`
4. **การตัดคำภาษาไทย (Word Tokenization):** ใช้ PyThaiNLP (newmm)
   * `สนใจตัวนี้อยู่มีสีอะไรบ้าง` ➡️ `["สนใจ", "ตัว", "นี้", "อยู่", "มี", "สี", "อะไร", "บ้าง"]`
5. **การลบคำขยะ (Token Cleaning):** ลบ token ที่ไม่มีความหมาย เช่น `อะ` `น้า` `เนอะ`
   * `โอนแล้วน้าา` ➡️ `["โอน", "แล้ว"]`
6. **การปรับโครงสร้างประโยค (Sentence Adjustment):** แปลงเป็นประโยคมาตรฐานตามเจตนา
   * `ส่งของยัง` ➡️ `สินค้าจัดส่งแล้วหรือยัง`
7. **การเติมคำสุภาพ (Add Polite Particle):** ใช้ครับ/ค่ะ/คะ ตามเพศของหางเสียงและชนิดประโยค (คำถามใช้ "คะ")
   * `สนจัยตัวนี้อยุ่ มีสีไรบ้างคะะะ` ➡️ `สนใจตัวนี้อยู่มีสีอะไรบ้างคะ`
8. **การจำแนกเจตนา (Intent Classification):** ตรวจคีย์เวิร์ดเรียงจากเคสเฉพาะไปเคสทั่วไป
   * `ส่งของยัง` ➡️ `สอบถามสถานะสินค้า`

**เจตนาที่รองรับ (12 ชนิด รวมข้อความทั่วไป):** ทักทาย, ขอบคุณ, ยกเลิกคำสั่งซื้อ, สินค้ามีปัญหา, ร้องเรียนการจัดส่ง, สอบถามการชำระเงิน, สอบถามการจัดส่ง, สอบถามสถานะสินค้า, แจ้งชำระเงิน, ขอเปลี่ยนสินค้า, สอบถามรายละเอียดสินค้า, ข้อความทั่วไป

## 🧠 ความสามารถขั้นสูง (Advanced Capabilities)

### 1. การจัดการความกำกวมของภาษา (Ambiguity Management)
* **ระดับคำ (Lexical):** *"ขอเปลี่ยนหน่อย"* อาจเป็นเปลี่ยนสินค้า ไซส์ หรือสี ระบบดูคำรอบข้าง เช่น *"เสื้อตัวนี้ไซส์เล็กไป ขอเปลี่ยนหน่อย"* ➡️ **"ต้องการขอเปลี่ยนไซส์สินค้า"**
* **โครงสร้างประโยค (Structural):** *"พัสดุถึงไหนแล้ว"* ➡️ *"สินค้าถึงขั้นตอนไหนของการจัดส่งแล้ว"*
* **ภาษาพูด (Informal):** *"ได้ของยัง"* ➡️ *"ได้รับสินค้าแล้วหรือยัง"*
* **คำที่มีหลายความหมาย:** *"ส่งช้า"* (ร้องเรียน) ต่างจาก *"ส่งยัง"* (สอบถามสถานะ) และ *"ส่งมาผิดไซส์"* (สินค้ามีปัญหา) ระบบแยกได้ด้วยลำดับกฎ

### 2. การสกัดข้อมูล (Information Extraction)
ดึงประเภทสินค้าและคุณสมบัติที่ถาม (สี ไซส์ ราคา)
* `เสื้อตัวนี้มีสีอะไร` ➡️ `Product: เสื้อ`, `Attribute: สี (Color)`

### 3. การจำแนกเจตนาด้วยกฎ (Rule-based Classification)
จัดข้อความเข้ากลุ่มเจตนา เช่น กลุ่มสอบถามสถานะ (`ส่งของยัง`, `พัสดุถึงไหนแล้ว`) และกลุ่มแจ้งชำระเงิน (`โอนแล้ว`, `โอนเงินเรียบร้อย`) ด้วยกฎคีย์เวิร์ด ไม่ได้ใช้โมเดลเรียนรู้หรือการทำ Clustering

## 🔗 การทำงานร่วมกับ MatchaQ (System Integration)

ระบบ ChatLert ถูกนำมาใช้งานเชื่อมโยงกับระบบ **MatchaQ** (ระบบวิเคราะห์ Job Description และ Portfolio) โดยแบ่งหน้าที่กันดังนี้:
* **ChatLert (Data Preprocessing):** ตรวจสอบ แก้ไขคำสะกดผิด และปรับภาษาแชทให้เป็นมาตรฐาน เพื่อลดปัญหาการตีความผิดพลาด
* **MatchaQ (Core Analytics):** รับข้อความที่ถูกต้องจาก ChatLert ไปสกัดคีย์เวิร์ด/ทักษะ เพื่อประเมินคะแนนความสอดคล้อง (Matching Score) ต่อไป

## 💻 การติดตั้งและการใช้งาน (Installation & Usage)

1. **โคลนโปรเจกต์**
   ```bash
   git clone https://github.com/similannaps/chatlert-nlp.git
   cd chatlert-nlp
   ```
2. **ติดตั้งไลบรารี**
   ```bash
   pip install -r requirements.txt
   ```
3. **รันชุดทดสอบ**
   ```bash
   python tests/test_engine.py
   ```
4. **ทดลองเอนจินใน Python**
   ```python
   import sys; sys.path.append("api")
   from engine import ChatLertEngine
   print(ChatLertEngine().process("สินค้าถึงวันหนายยยค่าา")["step_5_7"])
   ```
5. **รันทั้งเว็บในเครื่อง (ไม่บังคับ)**
   ```bash
   npx vercel dev
   ```
6. **Deploy:** Import รีโปที่ https://vercel.com/new แล้วกด Deploy

### สิ่งที่ปรับจาก v1 เป็น v2
| ปัญหาใน v1 | ตัวอย่าง v1 | v2 |
| :--- | :--- | :--- |
| ตัดหางเสียงด้วย `rstrip` ซึ่งตัดทีละตัวอักษร ทำให้ตัวอักษรหาย | `ราคาเท่าไหร่คับ` ➡️ ราคาเท่าไห**ครับ** | ราคาเท่าไหร่ครับ |
| ลดตัวซ้ำทุกคู่ ทำลายคำที่ซ้ำตามปกติ | `ยกเลิกออเดอร์` ➡️ ยกเลิก**อ**เดอร์ | คงคำเดิม |
| ตัวซ้ำคู่ท้ายคำไม่ถูกลด | `มีสีไรบ้างง` ➡️ ...บ้างง | ...บ้าง |
| เจอคำว่า "ส่ง" แล้วตีเป็นสอบถามสถานะทุกกรณี | `ทำไมส่งช้าจังงงงงง` ➡️ สินค้าจัดส่งแล้วหรือยัง | จัดส่งสินค้าล่าช้า ต้องการให้ตรวจสอบ (ร้องเรียนการจัดส่ง) |
| ไม่มีเจตนาสำหรับเรื่องที่พบบ่อย | `ส่งมาผิดไซส์ค่ะ` ➡️ สอบถามสถานะ | ได้รับสินค้าไม่ตรงกับที่สั่ง ต้องการแก้ไข (สินค้ามีปัญหา) |
| ไม่รู้จักการยกเลิกและการขอบคุณ | `ขอบคุณมากนะคะ` ➡️ ขอบคุณมาก**นค่ะ** | ขอบคุณมากค่ะ (ขอบคุณ) |
| นับ "ขา" ใน "ขาย" เป็นหางเสียง จึงเติมหางเสียงที่ลูกค้าไม่ได้พิมพ์ | `มีขายไหม` ➡️ มีขายไหม**คะ** | มีขายไหม (ตรวจหางเสียงที่ท้ายคำเท่านั้น) |

* หนึ่งข้อความได้เจตนาเดียว หากลูกค้าพูดหลายเรื่องพร้อมกัน ระบบเลือกเรื่องที่ตรงกฎก่อน
* ชุดทดสอบเขียนโดยผู้พัฒนาเอง จึงยังไม่ใช่การวัดความแม่นยำกับข้อมูลจริงจำนวนมาก
